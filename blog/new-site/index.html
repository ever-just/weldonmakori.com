New site, same Weldon

September 18, 2026

My personal site went down earlier this year — the domain lapsed, the backend server I was using went away, and weldonmakori.com quietly stopped resolving. It happens when you're busy building other things.

So I rebuilt it. This version is simpler on purpose: a fully static site, no database, no server to babysit, no admin panel. The whole thing is a git repository — every page is generated at build time and served from a CDN. If I want to change something, I edit a file and push. That's it.

What's here:

  • Work — a decade of sales, operations, and building, from a window cleaning company I co-founded at 19 to scaling an AI consultancy as COO.
  • School — the long road through business law and actuarial science at St. Thomas.
  • Writing — this blog. Expect posts about building Everjust, AI agents, insurance, and whatever else I'm thinking about.
  • Call — a video call page that works right in the browser. Try it.
